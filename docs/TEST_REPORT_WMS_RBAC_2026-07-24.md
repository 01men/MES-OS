# WMS 与权限模型多角色测试报告

测试日期：2026-07-24  
测试对象：MES OS WMS + RBAC + 钉钉 OAuth 骨架  
结论：自动化范围内通过；真实钉钉应用与生产环境专项测试待完成。

新增验证：

- 11 个岗位账号全部登录成功，返回唯一预期角色。
- 三轮权限矩阵：每轮 88 次查询鉴权，共 264 次。
- 三轮高风险主数据写入鉴权：每轮 11 次，共 33 次。
- 角色矩阵合计 297 次授权决策，全部符合配置；另完成 11 次身份登录。
- 临时授权创建后立即生效、撤销后立即失效，并产生创建/撤销审计。
- 钉钉 OAuth state 只能消费一次；绑定、JWT 登录、解绑及审计模拟闭环通过。
- 浏览器抽查：管理员权限页加载 11 用户；IT运维菜单过滤正确且越权路由重定向。
- 浏览器复验：权限页新增仓库数据范围列，11 用户显示正确；销售为 `WH02`，仓储/质量岗位为 `WH01`。
- 新增仓库数据范围闭环：列表过滤、显式跨仓查询拒绝、跨仓写入拒绝、旧 JWT 即时生效、审计留痕。
- 幂等响应不能绕过仓库范围校验；同一请求号由管理员成功执行后，未授权用户重放仍返回 403。
- 幂等命名空间包含用户与仓库范围指纹；同一用户范围变更后不会命中变更前的缓存响应。
- 移库同时校验源仓和目标库位，成功跨仓后批次的 `warehouseCode/locationCode` 保持一致。
- 到货单列表、详情和标签补打均执行仓库范围校验。

## 5. 钉钉登录测试

已通过自动化：

1. 未配置时不显示有效登录能力。
2. OAuth URL 包含 `client_id`、`redirect_uri`、`scope=openid` 与随机 state。
3. state 十分钟有效且只能使用一次，回调重放被拒绝。
4. 已登录用户可绑定钉钉 unionId。
5. 已绑定 unionId 可换取 MES JWT，并继承本地角色与权限。
6. 自助解绑和管理员解绑均写审计。
7. AppSecret 仅从服务端环境变量读取，不下发前端。

待实网验收：

- 钉钉开放平台创建企业内部应用。
- 配置授权回调域名和 `MES_PUBLIC_ORIGIN`。
- 使用真实 Client ID/Client Secret 完成 PC 扫码与钉钉客户端一键授权。
- 验证反向代理 HTTPS、SameSite/CSP、错误页、账号停用、换绑和离职回收。

## 6. 缺陷与风险

| 等级 | 风险 | 建议 |
| --- | --- | --- |
| P1 | 仓库数据范围已覆盖库存、收料及仓库/库位主数据；部门/本人范围尚未落地 | 随生产、质量模块扩展部门/产线/工单范围 |
| P0 | sql.js + `synchronize:true` 不适合生产 | 迁移 PostgreSQL 并建立 migration |
| P0 | 真实 U8 与真实钉钉未联调 | 建立沙箱、超时、重试、对账和实网验收 |
| P1 | 部分新业务控制器依赖服务层角色判断，尚未全部声明显式权限 | 按接口矩阵逐个收紧，禁止全局按 HTTP 方法推导 |
| P1 | 离线 1000 条、并发与断网恢复尚未压测 | 建立性能基线与设备专项测试 |
| P1 | 演示账号密码固定 | 生产 seed 禁用演示用户，实施密码与会话策略 |
| P2 | 业务入口已拆至约 21 KB，但 Element Plus 公共 chunk 约 800 KB | 后续改为组件按需引入 |
