# 聚杰电器 MES OS 功能蓝图

更新日期：2026-07-24

## 1. 产品边界

MES OS 定位于 ISA-95 Level 3 制造运营管理层，向上承接 U8/ERP 的计划、采购、销售与财务数据，向下连接设备、PLC、扫码枪、电子秤、标签机和 AGV。系统不替代 ERP，也不直接承担 PLC 的实时安全控制。

ISA-95 将 Level 3 制造运营划分为生产、库存、质量、维护等活动，并强调 Level 3 与 Level 4 之间的标准化信息交换。本项目应以这四类运营闭环为长期领域边界，而不是继续堆叠互不关联的页面。

参考：

- [ISA-95 标准与五层模型](https://www.isa.org/standards-and-publications/isa-standards/isa-95-standard)
- [ISA MES/MOM 功能范围摘录](https://www.isa.org/getmedia/6f55cb74-0bf1-4fd4-aac9-9d0b1be443eb/Manufacturing-Execution-Systems-Second-Ed-Excerpt-and-Table-of-Contents.pdf)

## 3. 目标功能地图

### 3.1 平台底座

- 组织模型：集团、工厂、车间、产线、工位、仓库、库区、库位。
- 资源模型：人员、班组、技能、设备、工装、模具、物料、批次、序列号。
- 身份权限：本地账号、钉钉 OAuth、RBAC、临时授权、ALL/DEPT/SELF/WAREHOUSE 数据范围、职责分离。
- 流程引擎：审批、电子签名、超时升级、待办、消息通知。
- 规则中心：版本化业务规则、生效时间、灰度范围、审计与回滚。
- 集成平台：U8、PLM、QMS、设备、钉钉；幂等、重试、死信、重放、对账。
- 审计合规：登录、授权、主数据、库存、质量、生产与集成操作的不可抵赖记录。

### 3.2 WMS 库存运营

- 收货：采购到货、ASN、条码扫描、暂存、IQC、合格/待检/冻结/不合格入库。
- 上架：库位推荐、混批/混料限制、容量约束、任务分派、扫码确认。
- 库内：移库、合并/拆分包装、状态转换、冻结、占用、释放、效期与库龄。
- 生产物流：齐套计算、波次备料、拣配、交接、线边仓、退料、补料、余料、挪料。
- 盘点：ABC/循环/指定盘点、盲盘、复盘、软冻结、差异审批、自动调整。
- 发运：发货通知、波次拣货、复核、装箱、序列号、照片、短装审批、出库。
- 追溯：批次/序列号正反向追踪、供应商→来料→工单→成品→客户。
- 库存策略：安全库存、FEFO/FIFO、呆滞料、有效期、Min/Max、补货建议。
- 移动与离线：PDA 离线队列、稳定任务号、冲突处理、断点续传、设备绑定。

### 3.3 生产运营

- 生产计划：ERP 计划下达、有限/无限产能排程、插单、冻结窗口、欠料约束。
- 工艺：多层 BOM、工艺路线、工序、工作中心、替代料、版本与生效控制。
- 工单：下达、开工、暂停、恢复、完工、关闭、拆单/合单、委外。
- 工序任务：人员/设备派工、开工/完工、实际工时、部分完工、转序、WIP。
- 投料与消耗：扫码投料、防错、替代料审批、超领、补料、倒冲、损耗。
- 报工：良品、不良、返工、报废、工时、设备时间、参数和附件。
- 现场管理：电子 SOP、Andon、异常升级、交接班、班组看板、在制品可视化。

### 3.4 质量运营

- 来料 IQC、过程 IPQC、完工 FQC、出货 OQC。
- 检验模板、质量控制点、抽样方案、量测/判定/照片型检查。
- NCR、不合格隔离、MRB 评审、让步接收、返工返修、报废。
- SPC、控制图、超限预警、首件/巡检/末件。
- 供应商质量、批次质量履历、质量成本与缺陷 Pareto。

### 3.5 设备与维护运营

- 设备台账、层级、能力、状态、点检、保养、校准。
- 设备采集：运行/停机、产量、报警、关键工艺参数。
- 停机原因、Andon、维修工单、备件领用、MTBF/MTTR。
- OEE：可用率、性能率、质量率及损失树。
- 预测性维护作为后续能力，不在首期替代现有 TPM 管理。

### 3.6 经营分析

- 交付：计划达成率、准时完工率、欠料与延期。
- 生产：产量、节拍、WIP、一次通过率、返工率、损耗。
- 仓储：账实准确率、库位利用率、库存周转、呆滞料、拣货及时率。
- 质量：来料/过程/成品不良率、供应商质量、缺陷 Pareto。
- 设备：OEE、停机、MTBF、MTTR、能耗单耗。
- 数据必须可下钻到原始单据、批次、工单、人员、设备和审计日志。

## 4. 权限模型目标

采用“RBAC 角色能力 + 数据范围 + 业务状态机 + 职责分离”四层控制：

1. RBAC 决定能否进入功能和执行动作。
2. 数据范围限定工厂、仓库、库区、部门或本人数据。
3. 状态机限定当前单据状态可执行的动作。
4. 职责分离限制自审、制单/复核同人、盘点/复盘同人、质量调拨电子签等场景。

当前已实现 RBAC、临时授权、审批防自审和部分服务层岗位校验；下一阶段必须优先落地仓库/部门数据范围，禁止仅依赖前端菜单隐藏。

## 5. 分阶段路线图

### P0：平台与 WMS 稳定化（当前—4 周）

- PostgreSQL + migration，关闭 `synchronize:true`。
- 完成钉钉生产应用配置、实网绑定/登录/解绑验收。
- 建立逐接口权限矩阵，落实仓库/部门数据范围。
- 补齐用户启停、密码策略、会话撤销、临时授权自动清理。
- 离线 1000 条压力与冲突测试；上传文件安全、对象存储。
- U8 沙箱/真实接口适配、10 秒 SLA、重放与日终对账。

验收门槛：关键写接口 100% 幂等；11 岗位权限矩阵 100%；库存账实与追溯链可复核；无默认生产密钥。

### P1：WMS 生产级闭环（4—10 周）

- ASN/上架/波次/补货/装箱/库位策略。
- FEFO/FIFO、效期、呆滞料、容量与混储规则。
- 生产物流全链：齐套→备料→交接→线边仓→退补余挪料。
- 仓库主管看板、异常待办、库存准确率指标。

### P2：MES 核心执行（10—20 周）

- 工艺路线、工作中心、工单、工序任务、派工、报工、WIP。
- 投料防错、替代料、倒冲、损耗、返工、报废。
- 电子 SOP、班组终端、Andon、交接班。
- 计划/实际工时、产量、节拍和进度看板。

### P3：QMS 与设备运营（20—30 周）

- QCP、抽样方案、IPQC/FQC/OQC、NCR/MRB、SPC。
- 设备台账、点检保养、停机、维修、备件、OEE。
- 工艺参数与质量结果关联，形成产品电子履历。

### P4：优化与智能化（30 周以后）

- 有限产能排程、物料/设备/人员多约束仿真。
- 预测交付风险、质量趋势、设备异常和库存优化建议。
- 多工厂复制、数据平台、指标语义层与自助分析。

## 6. 架构原则

- 领域边界优先：生产、库存、质量、维护分别建模，通过事件和明确契约协作。
- API 契约、状态机、审计、幂等与权限属于后端能力，前端不得替代。
- 设备侧断网时仍应保证安全控制；MES 下发指令不能绕过 PLC/设备安全逻辑。
- 所有外部集成都要有业务键、请求号、重试上限、死信、人工重放和对账。
- 配置、BOM、工艺、权限与规则必须版本化并记录生效时间。
- 先形成可验证闭环，再扩展页面数量；每项能力都要有角色、异常、审计和性能验收。
